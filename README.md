PYTHON-EXPENCE TRACKER

1) Features-
   Allows the user to add expenses,
   search for a particular expense through a category,
   calculate the total expense, and
   view the expenditure.

2) Concepts used-
   CSV file handling,
   functions,
   if-else conditionals, and
   loops.

3) Future plans-
   I plan to improvise this project by adding charts using math-plot-lib (once I learn it) and suggest the user areas, where the expenses can be cut.
